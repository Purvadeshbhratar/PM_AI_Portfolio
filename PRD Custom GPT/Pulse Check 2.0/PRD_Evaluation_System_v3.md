# PRD Evaluation System – v3 (Persona-Aware Review Engine)

This system evaluates PRDs by simulating **real-world stakeholder reviews**.
The same PRD may receive **different decisions** depending on who is evaluating it.

## How It Works

1. The evaluator persona is mandatory before scoring.
2. Persona-specific overrides adjust priorities, tolerance, and decision rules.
3. Explicit grading criteria always override defaults.
4. Output focuses on **decision realism**, not checklist completeness.

## Supported Personas
- Leadership / VP Product
- Hiring Manager (PM interviews)
- Engineering Lead
- PM Peer
- QA / Risk
- AI / Data Reviewer

## Core Outputs
- Persona-adjusted evaluation
- Approve / Reject / Revise decision
- Blocking issues
- Review-meeting questions
- Coaching feedback
- Score traceability

This framework mirrors how PRDs are judged in real product organizations.
