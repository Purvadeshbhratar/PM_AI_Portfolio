# PRD Evaluation System – v2

This document defines a real-world, persona-aware PRD evaluation framework.

## Key Principles
- Evaluation depends on evaluator persona and product stage
- Decisions matter more than raw scores
- Assumptions, risk, and reversibility are first-class signals

## Outputs
- Dimension-based scores
- Approval / rejection simulation
- Coaching feedback
- Traceability from score to PRD section
